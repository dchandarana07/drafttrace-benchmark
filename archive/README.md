# Archive

Material from the previous release of this repository, kept because published
work cites it.

- `kappa/` — an independent per-character agreement study (Cohen's kappa) on
  writing provenance: 30 essays, 39,976 characters, an adjudicator blind to the
  system's own labels re-attributing origin from the recorded evidence alone.
  Its README and `score.py` are unchanged; the score is reproducible from the
  released files.

Everything else that this repository previously held — the reconstruction
recipes, labels, end-to-end results and the transplant suite — remains in the
git history and can be recovered from it. It was removed from the working tree
because this repository is now a benchmark for writing-process *recorders*, and
carrying a differently-scoped dataset alongside it made both harder to read.
